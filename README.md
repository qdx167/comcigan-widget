# 컴시간 교사 시간표 위젯

아이폰·아이패드 홈 화면에 컴시간 교사 시간표를 보여주는 [Scriptable](https://scriptable.app) 위젯입니다.

## 설치

1. App Store에서 **Scriptable**을 설치합니다.
2. `컴시간_교사시간표.js` 파일을 받아 Scriptable로 엽니다(AirDrop이나 파일 앱으로 받은 뒤 공유 → Scriptable).
3. Scriptable에서 스크립트를 실행하면 설정 화면이 열립니다. 학교 코드를 넣고 선생님을 고른 다음 교시 시각을 확인하고 저장합니다.
   - 학교 코드는 컴시간알리미 앱이나 컴시간교사.kr에서 학교를 검색하면 나옵니다.
4. 홈 화면을 길게 눌러 Scriptable 위젯을 **중간 크기**로 추가하고, 위젯 편집에서 이 스크립트를 고릅니다.

## 사용

- 위젯을 탭하면 주간 시간표와 반별 시간표가 열립니다.
- 설정은 확대 화면 맨 아래 **⚙ 설정**에서 바꿉니다. 스크립트 버전과 마지막 업데이트 확인 시각도 여기에 나옵니다.
- **오류 ›** 표시가 뜨면 확대 화면에서 눌러 원인과 해결 방법을 확인하세요. **오류 내용 보내기**로 만든 사람에게 바로 보낼 수 있습니다.
- 새 버전이 나오면 확대 화면 위쪽에 안내가 뜹니다. 새 파일로 덮어써도 설정은 그대로 남습니다.

## 참고

- 컴시간은 공식 API가 없어 사이트가 크게 바뀌면 동작이 멈출 수 있습니다.
- 위젯은 하루에 한 번 이 저장소의 `version.json`만 읽어 새 버전과 공지를 확인합니다. 그 밖의 정보는 어디에도 보내지 않습니다.
