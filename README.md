# 컴시간 교사 시간표 위젯

아이폰·아이패드 홈 화면에 **오늘 내 수업**을 보여주는 위젯입니다.
위젯을 누르면 이번 주·다음 주 시간표와 반별 시간표를 볼 수 있어요.
**Scriptable**이라는 무료 앱 위에서 동작합니다.

> 받을 파일은 하나뿐이에요. 아래 순서대로 따라 하면 5분 정도 걸려요.
> 이 페이지의 다른 파일(`update` 폴더 등)은 받지 않아도 됩니다.

---

## 1. Scriptable 앱 설치

App Store에서 **Scriptable**을 검색해 설치합니다. 무료이고, 아이콘은 검은 바탕에 흰 글씨 `{ }` 모양입니다.

## 2. 스크립트 복사하기

1. 아이폰에서 **👉 [스크립트 열기](https://raw.githubusercontent.com/qdx167/comcigan-widget/main/%EC%BB%B4%EC%8B%9C%EA%B0%84_%EA%B5%90%EC%82%AC%EC%8B%9C%EA%B0%84%ED%91%9C.js)** 를 누르세요. 글자(코드)만 가득한 페이지가 열려요.
2. 글자 아무 곳이나 **길게 누른 뒤**, 나오는 메뉴에서 **전체 선택**을 누르세요.
   - 메뉴에 "전체 선택"이 안 보이면 메뉴의 `›` 화살표를 눌러 넘겨보세요.
3. 파랗게 선택되면 **복사**를 누르세요.

## 3. Scriptable에 붙여넣기

1. Scriptable 앱을 엽니다.
2. 오른쪽 위 **+** 버튼을 누르면 빈 화면이 열려요.
3. 빈 화면을 한 번 누른 뒤 **붙여넣기**를 누르세요.
4. 화면 맨 위의 제목(`Untitled Script`)을 눌러 이름을 **컴시간 시간표**로 바꿉니다.
5. 왼쪽 위 **Done**을 누르면 목록에 파란색 아이콘의 "컴시간 시간표"가 생겨요.

## 4. 처음 설정

1. 목록에서 **컴시간 시간표**를 누르면 **내 시간표 설정** 화면이 열려요.
2. **우리 학교 찾기**에 학교 이름 일부나 전달받은 학교 코드를 넣고 **찾기**를 누르세요.
3. 이름으로 찾았다면 목록에서 우리 학교를 누르세요. 선생님 목록을 불러와요.
4. **선생님**에서 본인 이름을 고르세요. (컴시간은 이름 끝 글자를 `*`로 가려서 보여줘요.)
5. 하루 교시 수, 교시별 시각, 점심시간을 확인하고 **저장**을 누르세요.
   - "컴시간에 등록된 시작 시각으로 채우기"를 누르면 시각을 한 번에 채울 수 있어요.

> 설정은 iCloud에 저장되어, 같은 Apple 계정을 쓰는 아이패드에서도 그대로 쓰여요.

## 5. 홈 화면에 위젯 추가

1. 홈 화면 빈 곳을 **길게 누르고**, 왼쪽 위 **편집** → **위젯 추가**를 누르세요.
2. 목록에서 **Scriptable**을 찾아 누른 뒤, 옆으로 넘겨 **중간 크기**(가로로 긴 것)를 고르고 **위젯 추가**를 누르세요.
3. 홈 화면에 생긴 빈 위젯을 **길게 누르고** → **위젯 편집**을 누르세요.
4. 아래처럼 고릅니다.
   - **Script**: 컴시간 시간표
   - **When Interacting**: Run Script
5. 바깥을 눌러 닫으면 시간표가 나타나요.

---

## 쓰는 법

- **위젯을 누르면** 주간 시간표와 반별 시간표가 열려요.
- 맨 아래 **⚙ 설정** → **내 시간표 설정**의 **바꾸기**에서 학교·선생님·교시를 바꿀 수 있어요. 테마 색도 여기서 골라요.
- 위젯에 **오류 ›** 나 **⚠ 오프라인** 이 보이면, 위젯을 눌러 연 화면에서 그 표시를 누르세요. 원인과 해결 방법이 나와요.
  만든 사람에게 알리고 싶으면 **오류 내용 보내기**를 눌러 카카오톡이나 문자로 보내주세요.
- 새 버전이 나오면 위젯을 눌러 연 화면 위쪽에 안내가 떠요.

## (선택) 위젯을 바로 새로고침하는 아이콘 만들기

위젯은 아이폰이 정한 때에 새로 그려져서, 가끔 시간표가 늦게 바뀔 수 있어요.
홈 화면에 아래 아이콘을 하나 만들어 두면, 누를 때마다 위젯을 바로 새로 그려요.

1. **단축어** 앱을 열고 오른쪽 위 **+** 버튼을 누르세요.
2. 아래 검색칸에 `Refresh`를 입력하고, Scriptable 아이콘(`{ }`)이 붙은 **Refresh all widgets**를 누르세요.
3. 다시 검색칸에 `홈 화면`을 입력하고 **홈 화면으로 이동**을 누르세요.
   - 이 동작이 있어야 Scriptable 앱이 잠깐 열렸다가 바로 홈 화면으로 돌아와요.
4. 맨 위 이름을 눌러 **이름 변경**에서 `위젯 새로고침`으로 바꾸세요. 같은 메뉴의 **아이콘 선택**에서 색과 모양도 고를 수 있어요.
5. 같은 메뉴에서 **홈 화면에 추가** → 오른쪽 위 **추가**를 누르세요.

이제 홈 화면의 **위젯 새로고침** 아이콘을 누르면 Scriptable이 잠깐 열렸다 닫히면서 위젯이 새로 그려져요.
(아이폰 구조상 Scriptable이 잠깐 열리는 건 피할 수 없어요.)

## 새 버전으로 바꾸기

1. 위 **2번**처럼 스크립트를 다시 복사합니다.
2. Scriptable 목록에서 **컴시간 시간표**를 **길게 누르고** → **Edit Script**를 누르세요.
3. 글자를 길게 눌러 **전체 선택** → **붙여넣기**로 통째로 바꾸고 **Done**을 누르세요.

설정과 위젯은 그대로 남아 있어요.

---

## 참고

- 컴시간은 공식 연동 방법이 없어서, 컴시간 사이트가 크게 바뀌면 잠시 멈출 수 있어요. 그럴 땐 새 버전을 기다려 주세요.
- 위젯은 컴시간 사이트에서 시간표만 받아오고, 하루 한 번 이 저장소의 `update/version.json`을 읽어 새 버전이 있는지 확인해요. 그 밖의 정보는 어디에도 보내지 않아요.
- (선택) 위젯 편집의 **Parameter**에 교사 번호를 적으면 다른 선생님의 시간표를 볼 수 있어요.
